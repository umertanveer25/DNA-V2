\begin{abstract}
Accurate automated classification of software requirements into functional specifications (FR) and fine-grained non-functional quality attributes (NFR) is fundamental to software architecture design, traceability maintenance, and safety-critical compliance, particularly under accelerating code complexity and compressed development lifecycles. Conventional requirements engineering pipelines rely predominantly on static term-frequency heuristics or large-scale pre-trained transformer language models; while transformers provide strong semantic comprehension, they exhibit prohibitive computational overhead, subword token truncation, and severe vulnerability to real-world class distribution skew, whereas earlier bio-inspired paradigms mapped requirements into crude, static single-nucleotide letters ($A, T, C, G$), achieving an accuracy ceiling of $78.67\%$ and failing to represent syntactic-semantic coupling. This study presents \textbf{DNA+}, a bio-inspired genomic sequence engineering framework that integrates dynamic syntactic-semantic dinucleotide codon mapping ($\text{Base}_1 \text{ [Primary Anchor]} + \text{Base}_2 \text{ [Auxiliary Dependency]}$) with dense Sentence-BERT embeddings and alignment-free oligonucleotide frequency statistics to generate high-fidelity, interpretable requirement representations without requiring dedicated GPU infrastructure for routine deployment. The framework synthesizes genuine biological nucleotide sequences in FASTA format and couples a 23-dimensional genomic physicochemical profile ($k$-mer frequencies, 16 dinucleotide relative abundance ratios, Shannon information entropy, and GC-content) with a 50-dimensional TF-IDF vector and a 384-dimensional dense SBERT semantic vector into a rich 457-dimensional manifold, paired with an ensemble classification engine and a dual-tier explainable AI (XAI) diagnostic suite (TreeSHAP and LIME). DNA+ was evaluated across three benchmark corpora comprising 8,654 authentic software requirements---canonical PROMISE ($N=625$), extended P-EXP ($N=969$), and industrial-scale FNFC ($N=7,060$)---under a rigorous 10-fold cross-validation protocol repeated across 30 randomized splits (300 evaluations per algorithm) without synthetic oversampling distortion. The framework achieved a peak classification accuracy of $94.77\%$ and a Macro-F1 score of $93.90\%$ on industrial FNFC ($+17.42\%$ over the Paper~1 baseline), while sustaining an accuracy of $90.40\% \pm 1.25\%$ (Macro-F1: $89.82\% \pm 1.41\%$) and a macro ROC-AUC of $0.9924$ across the 9-class dinucleotide benchmark. Under severe class imbalance (up to $76:1$), the framework retained a macro PR-AUC of $0.9361$, representing an $8.4\times$ improvement over the empirical random chance baseline ($AP = 0.111$). Inferential statistical testing confirmed statutory superiority over prior baselines through parametric paired Student's $t$-test ($t = 11.6865, p = 2.4 \times 10^{-5}$), non-parametric Wilcoxon signed-rank test ($W = 28.0, p = 0.00781$), Mann-Whitney $U$ test ($U = 49.0, p = 0.00100$), and an extreme effect size (Cohen's $d = 4.417$, Hedges' $g = 4.135$, Cliff's Delta $\delta = 1.000$). Component feature ablation demonstrated the indispensability of the genomic module, as ablating biological sequence features caused an immediate $31.89\%$ performance collapse ($57.28\%$ vs. $89.17\%$). The main novelty of this study lies in formulating a dynamic context-aware dinucleotide codon grammar that maps syntactic dependencies directly to biological sequence topologies, proving that compact bio-inspired genomic representations provide orthogonal discriminative signals that resolve vocabulary mismatch and class imbalance in empirical software engineering.
\end{abstract}
